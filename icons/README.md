# 人生蛇棋 · Life Snakes & Ladders

掷骰子走完生、老、病、死的一生。路上可以购买医药卡、疾病保险、人寿保险和储蓄计划，
看看保险什么时候接住你。适合保险知识工作坊，2–4 人同屏轮流玩。

## 玩法
- 棋盘 1–100 格，分为求学成长、初入职场、成家立业、中年打拼、退休人生五个阶段。
- 梯子是好的人生选择，蛇是人生风险。
- 有对应保单：保险赔付，不用滑下去；没有保单：自付费用并滑下去。
- 越年轻投保越便宜，退休后不能投保。
- 必须刚好走到 100；掷到 6 可再掷一次。

## 安装成 App
本项目是 PWA（渐进式网页应用），部署到 GitHub Pages 后：
- **手机（Android / Chrome）**：打开网址 → 菜单 → “安装应用 / 添加到主屏幕”
- **iPhone（Safari）**：打开网址 → 分享 → “添加到主屏幕”
- **电脑（Chrome / Edge）**：地址栏右侧的“安装”图标

安装后可离线游玩（字体在离线时会使用系统字体）。

## 部署
仓库 Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，保存即可。

## 提示词（COILO）
- **C 背景**：保险公司工作坊，面向非技术观众。
- **O 目标**：网页版人生蛇棋，体会保险的重要性。
- **I 输入**：2–4 位玩家，起步积蓄 RM 1,000，四种保单。
- **L 规则**：五个人生阶段；梯子=好选择，蛇=风险；有保单不滑不付钱；越早投保越便宜。
- **O 输出**：中文网页游戏，动画骰子、事件弹窗、结算对比表。
